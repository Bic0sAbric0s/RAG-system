# RAG Telegram Bot

Telegram-бот с RAG-системой (Retrieval-Augmented Generation) для работы с документами. Загружайте PDF, DOCX и TXT файлы прямо в чат — бот проиндексирует их и будет отвечать на вопросы по содержимому, используя локальную языковую модель.

---

## Возможности

- **Загрузка документов** — PDF, DOCX, TXT прямо через Telegram
- **Семантический поиск** — находит релевантные фрагменты по смыслу, а не по ключевым словам
- **Ответы на вопросы** — по содержимому загруженных документов
- **Три режима ответа:**
  - **Factual** — точный ответ из текста (определения, факты, цитаты)
  - **Analytical** — объяснение сути, краткий пересказ
  - **Reasoning** — сравнение, анализ, выводы
- **Список документов** с пагинацией по 10 штук
- **Удаление последнего документа** из базы
- **Кэширование ответов** — повторные вопросы отдаются мгновенно
- **Русский и английский** — мультиязычные embeddings и промпты
- **Локальный inference** — модель работает на вашем железе, без внешних API

## Стек технологий

| Компонент | Технология |
|-----------|-----------|
| **LLM** | [Qwen2.5-3B-Instruct](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct) |
| **Embeddings** | [intfloat/multilingual-e5-large](https://huggingface.co/intfloat/multilingual-e5-large) |
| **Векторная БД** | [ChromaDB](https://www.trychroma.com/) (persistent) |
| **Telegram Bot** | [aiogram 3.x](https://docs.aiogram.dev/) |
| **ML Framework** | PyTorch + Transformers |

---

## Требования

- **Python:** 3.10 или выше
- **RAM:** минимум 8 GB
- **GPU:** опционально. С GPU (4GB+ VRAM) работает значительно быстрее
- **Диск:** ~5 GB для моделей и зависимостей

> **Примечание:** без GPU бот работает, но индексация больших документов и генерация ответов занимают больше времени.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/rag-telegram-bot.git
cd rag-telegram-bot
```

### 2. Виртуальное окружение

**Linux / macOS:**
```bash
python -m venv venv
source venv/bin/activate
```

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

> **Для GPU (CUDA):** установите PyTorch с поддержкой CUDA заранее:
> ```bash
> pip install torch --index-url https://download.pytorch.org/whl/cu121
> ```
> Затем установите остальные зависимости.

### 4. Настройка окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и укажите токен вашего бота:

```env
BOT_TOKEN=your_telegram_bot_token_here
```

**Как получить токен:**
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен в `.env`

### 5. Запуск

```bash
python bot.py
```

В консоли появится:
```
CUDA available: True
Embedder device: cuda:0
Модель готова!
Документы в DB 0
```

Бот запущен — найдите его в Telegram по username и отправьте `/start`.

## Использование

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота, приветствие |
| `/help` | Основные команды |
| `/info` | Подробная справка по использованию |
| `/list` | Список загруженных документов (с пагинацией) |
| `/stats` | Статистика базы данных |
| `/delete` | Удалить последний загруженный документ |

### Загрузка документов

Просто отправьте боту файл в формате **PDF**, **DOCX** или **TXT**. Бот:

1. Скачает файл
2. Извлечёт текст
3. Разобьёт на чанки (1500 символов с перекрытием 100)
4. Сгенерирует embeddings
5. Сохранит в ChromaDB

Обработка занимает **1–2 минуты** в зависимости от размера файла и наличия GPU.

### Задавание вопросов

После загрузки документа напишите боту любой вопрос:

```
Вы: Что такое инфляция?
Бот: Инфляция — это устойчивое повышение общего уровня цен на товары и услуги.
```

Бот автоматически определит тип вопроса и выберет подходящий режим ответа.

## Конфигурация

### Параметры чанкинга

В `simple_rag.py`, метод `add_document`:

```python
self.chunks = self._chunk_text(text, chunk_size=1500, overlap=100)
```

- `chunk_size` — размер чанка в символах
- `overlap` — перекрытие между чанками

### Параметры генерации

В начале `simple_rag.py`:

```python
llm_pipeline = pipeline(
    'text-generation',
    model=model,
    tokenizer=tokenizer,
    max_new_tokens=200,
    temperature=0,
    do_sample=False,
    ...
)
```

### Смена модели

```python
# Для большей скорости (но ниже качество):
model_name = 'Qwen/Qwen2.5-0.5B-Instruct'

# Баланс:
model_name = 'Qwen/Qwen2.5-1.5B-Instruct'

# Лучшее качество (нужно больше VRAM):
model_name = 'Qwen/Qwen2.5-3B-Instruct'
```

## Известные ограничения

- **Скорость на CPU** — без GPU индексация может занимать 10+ минут для больших документов
- **Контекст LLM** — модель 0.5B иногда «разгоняет» ответ, добавляя лишнее (решается переходом на 1.5B+)
- **OCR не поддерживается** — PDF должен содержать текстовый слой, а не только картинки
- **Максимум 20 MB** на файл (ограничение Telegram Bot API)
- **Только один пользователь** — база общая для всех, кто пишет боту

---

## Безопасность

- Токен бота хранится в `.env`, который **не попадает в git**
- Модели работают **локально** — данные не отправляются на сторонние API
- Документы хранятся локально в `my_documents_db/`

> **Важно:** не коммитьте `.env` и `config.py` в репозиторий. Они указаны в `.gitignore`.
